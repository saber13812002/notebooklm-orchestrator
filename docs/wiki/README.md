# مستندات مشتری (Wiki.js) — Source of Truth

این پوشه **منبع Markdown** مستندات مشتری NLO است. هر فایل = یک صفحه در
Wiki.js. انتشار به Wiki.js (`docs.ai.ismc.ir`) **فقط پس از صدور دسترسی API**
انجام می‌شود (فاز E)؛ تا آن زمان هیچ صفحه‌ای به‌صورت خودکار منتشر نشده است.

## قوانین نگارشی

- صادقانه بودن: هر قابلیت با وضعیت واقعی‌اش ذکر می‌شود
  (`آماده/تست‌شده`، `live-verify شده`، `planned`).
- مثال‌ها باید با API واقعی کار کنند (روت‌های فعلی: `POST /api/jobs` و
  بقیه جدول در `09-api-guide.md`).
- هیچ Secret، توکن یا مقدار واقعی حساب در این صفحات نمی‌آید.
- پس از انتشار، لینک واقعی هر صفحه در جدول بالا و در `README.md` ثبت می‌شود.
