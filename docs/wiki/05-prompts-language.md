# تنظیم Prompt و زبان

## ساختار Prompt

`prompt` یک رشته‌ی آزاد است که مستقیماً به NotebookLM به‌عنوان سؤال/دستور
ارسال می‌شود. محدودیت: حداکثر طول قابل تنظیم است
(`jobsMaxPromptChars` در تنظیمات سرور).

نکات عملی:

- **زبان:** زبان پاسخ را می‌توان در خود prompt خواست، مثلاً
  `«پاسخ را به فارسی بده»`. NotebookLM به زبان source/سؤال پاسخ می‌دهد؛
  برای فارسی، صریح بخواهید.
- **خروجی ساختاریافته:** دستور مشخص بدهید (لیست، جدول، خلاصه‌ی X کلمه‌ای).
- **مرجع‌محور:** پاسخ‌های NotebookLM **grounded** هستند — بر پایه‌ی source
  آپلودشده. اگر source نداشته باشد، انتظار مرجع‌دار بودن را نداشته باشید.

## مثال‌ها

```bash
# خلاصه‌ی فارسی
curl -s -X POST http://127.0.0.1:4870/api/jobs \
  -F "prompt=خلاصه‌ی فارسی این گفتگو را در ۵ بند بده" \
  -F "audio=@interview.wav;type=audio/wav"

# استخراج ساختاریافته
curl -s -X POST http://127.0.0.1:4870/api/jobs \
  -F "prompt=اعداد نام‌برده‌شده را به ترتیب، هرکدام در یک خط جداگانه بنویس" \
  -F "audio=@numbers.wav;type=audio/wav"
```

## انتخاب account و node (اختیاری)

اگر prompt به حساب یا مسیر خاصی وابسته است:

- `preferredAccountId` — قفل روی یک حساب گوگل (مثلاً حسابی که quota دارد).
- `preferredNodeId` — قفل روی یک نود VLESS.

در نبود این فیلدها، انتخاب خودکار از بین حساب‌ها/نودهای `enabled` و سالم
انجام می‌شود.
