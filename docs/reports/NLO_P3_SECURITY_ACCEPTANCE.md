### Token / password strength

- **Machine API token**: format `nlo_` + 32-byte CSPRNG (code-verified: [`first-admin.ts`](apps/server/src/domain/first-admin.ts:41) — "plaintext is derived from a 32-byte CSPRNG … only its SHA-256 … is stored"). **256-bit secret, meets the ≥256-bit mission requirement.** Only the hash is in the DB; plaintext exists in exactly two 0600 files on the host + the final report.
- **Browser password**: `openssl rand -base64 18` = 16 random bytes = **128-bit** password, stored 0600 on the host, hashed with SHA-512 crypt in htpasswd.
- Both are **distinct credentials for distinct surfaces** (browser vs. machine API) — the Cloudflare token is a third, unrelated credential, used only for API verification of the account; it is not an NLO credential and is not stored in `.env`, git, or reports.
